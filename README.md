# Dashboard

A minimal personal task tracker that stores data in a private GitHub repository.

## Setup

1. Create a private GitHub repo to store your data.
2. Generate a [GitHub PAT](https://github.com/settings/personal-access-tokens) with **Contents: read & write** on that repo.
3. Open the app and click the settings button to enter your PAT, username, and repo name.

## Features

- Three status columns: In Progress, Backlog, Want
- Tag filtering
- Drag-and-drop reordering (mouse and touch)
- Installable as a PWA
